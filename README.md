# House Price Prediction using Linear Regression

## 📌 Overview
This project is a part of my Data Science Internship at Prodigy InfoTech.  
The objective of this project is to implement a Linear Regression model to predict house prices based on features like square footage and number of bedrooms.

---

## 🎯 Objective
To build a machine learning model that can predict house prices using Linear Regression.

---

## 📂 Dataset
The dataset contains housing-related information such as:
- Square footage
- Number of bedrooms
- House prices

---

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Jupyter Notebook

---

## ⚙️ Steps Performed
1. Imported required libraries  
2. Loaded and cleaned the dataset  
3. Selected important features  
4. Split data into training and testing sets  
5. Trained the Linear Regression model  
6. Predicted house prices  
7. Evaluated model performance  

---

## 📊 Model Used
- Linear Regression

---

## 📈 Outcome
Successfully developed a house price prediction model using Linear Regression.
