📌 Overview


This project is a part of my Data Science Internship at Prodigy InfoTech.
The objective of this project is to implement a Linear Regression model to predict house prices based on features like square footage and number of bedrooms.


🎯 Objective

To build a machine learning model that can predict house prices using Linear Regression.


📂 Dataset

The dataset used for this project contains housing-related information such as:
Square footage (SQUARE_FT)
Number of bedrooms (BHK_NO.)
House price (TARGET(PRICE_IN_LACS))


🛠️ Technologies Used

Python
Pandas
NumPy
Matplotlib
Scikit-learn
Jupyter Notebook


⚙️ Steps Performed

Imported required libraries
Loaded and cleaned the dataset
Selected important features
Split data into training and testing sets
Trained the Linear Regression model
Predicted house prices
Evaluated model performance


📊 Model Used

Linear Regression


📈 Outcome

Successfully built a Linear Regression model capable of predicting house prices based on selected input features.
